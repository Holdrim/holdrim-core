S04 If you are a developer

Holdrim is an engine: a Docker image your documentation mounts into, the way a product uses Keycloak. Your pages stay in your repository, in plain HTML.

1 Run it

Clone the engine and start it with the example: HOLDRIM_OWNER=you@example.org docker compose up, then open http://localhost:8080. The first-access password is printed once, in the log.

For your own documentation, copy examples/template, set the owner and the pages in holdrim.json, and mount the folder into the image.

2 The tool

holdrim lights prints the state of the whole documentation; holdrim apply hands an approved request to the AI tool you already use, running with your own account. The engine calls no model and holds no key.
