S03 If you are not a developer

You know what the system has to do. Holdrim is where you say it, check it and keep it true — without writing a line of code.

1 What you do

Read and approve. Each block has a number in its corner. Click it, read, and approve — or ask for a change in your own words.

See where things stand. The project home lists every page with its lights and every request still waiting, so you never have to hunt for what needs you.

Ask for what is missing. "Ask for a page" takes a sentence: what should be explained, and near which page. The rest follows the same cycle as any change.
